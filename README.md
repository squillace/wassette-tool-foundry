# Wassette Tool Foundry

Welcome to the Wassette Tool Foundry! This repository is a community-driven hub for requesting and developing new tools compatible with the [Wassette](https://github.com/microsoft/wassette) JavaScript WebAssembly component ecosystem.

## Purpose

The primary purpose of this repository is to allow users to create issues requesting the development of Wassette-compatible tools. These tools are designed to implement APIs that are useful for Wassette-based applications, enabling them to extend their functionality by integrating new WebAssembly components as tools.

## How It Works

1. **Request a Tool**: If you need a new Wassette-compatible tool that implements a specific API, open an issue in this repository. Clearly describe the API, its intended use, and any relevant details.
2. **Admin Approval**: Tool creation will only begin after a repository admin or owner adds Copilot to the issue. This ensures requests are reviewed and prioritized appropriately.
3. **Community Collaboration**: Once approved, contributors and maintainers will review requests, discuss requirements, and work together to design and implement the requested tool as a WebAssembly component using JavaScript.
4. **Tool Development**: The tool will be developed following Wassette standards, including WIT (WebAssembly Interface Types) definitions and JavaScript implementations.
5. **Integration**: Completed tools will be published in this repository, making them available for use in Wassette-based applications.

## What Is a Wassette-Compatible Tool?

A Wassette-compatible tool is a WebAssembly component built with JavaScript and WIT, designed to be loaded and used by applications built on the Wassette engine. These tools can implement any useful API, such as data processing, external service integration, or custom logic, and are easily composable within the Wassette ecosystem.

## Getting Started

- To request a new tool, [create an issue](https://github.com/squillace/wassette-tool-foundry/issues) describing your needs.
- To contribute, review open issues and join the discussion or submit pull requests with new tool implementations.
- For more information on building Wassette-compatible tools, see the [Wassette documentation](https://github.com/microsoft/wassette) and the [componentize-js](https://github.com/bytecodealliance/componentize-js) project.
